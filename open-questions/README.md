# open-questions/

Dossiers for open items whose analysis needs more than a few lines. The open item itself is always a
`REQ-nnn` in the requirements document's open-items section; a dossier here is pointed to from that
entry and never replaces it (`CONVENTIONS.md` §2). Name dossiers after the ID: `REQ-nnn-<topic>.md`.
Append-only once the item is resolved — the resolution is recorded at the source entry.
