# architecture/

The architecture document and any standalone `.mmd` diagrams. A Pattern B statement
(`CONVENTIONS.md` §5): edited in place, with a "Changed since v(n−1)" section stating what changed,
what was checked and found still valid, and what could not be verified. Diagrams follow §9 and are
rendered before being considered done.

Created by `create-architecture-doc`; changed by `modify-architecture-doc`; reviewed by
`review-architecture-doc`.
