# requirements/

The requirements document — the **master document** of the project, read in full at every session
start. A Pattern A register (`CONVENTIONS.md` §5): each `REQ-nnn` carries its own `SRC-x.y` links,
status, reviewer and append-only revision history. Includes an **open-items section**, the single
home for unresolved questions, missing inputs and cross-module blockers.

Created by `create-requirements-doc`; changed only by `modify-requirements-doc`; reviewed by
`review-requirements-doc`.
