# intermediary/

First-class working artifacts (`CONVENTIONS.md` §3, Pattern C in §5): surveys, extraction notes,
vocabulary reconciliations, coverage matrices, and **reviewers' independent derivations, written here
before the draft under review is opened.**

Structured for the next machine step, not for a reader. Retained — this is where the history of a
superseded draft lives, and where disagreement between sources becomes visible before anything is
merged. Name files so their producer and subject are evident, e.g.
`REVIEW-<nnn>-derivation-<artifact>.md`.
